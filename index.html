01 / INTRODUÇÃO

O que é Clean Code?

É a prática de escrever código fácil de ler, compreender e manter.

Entenda melhor

Código limpo comunica sua intenção. Ele evita complexidade desnecessária e facilita futuras modificações.

02 / NOMENCLATURA

Nomes significativos

Variáveis, métodos e classes devem ter nomes que expliquem sua finalidade.

Entenda melhor

Evite nomes genéricos, como x e temp, quando não comunicam o significado dos dados.

03 / ORGANIZAÇÃO

Funções

Cada função deve ter um propósito bem definido e fácil de entender.

Entenda melhor

Funções focadas em uma tarefa costumam ser mais simples de testar e modificar.

APROFUNDAMENTO 02

Funções e métodos

Escreva métodos claros e com objetivos definidos.

PRINCÍPIO 01

Responsabilidade única

Cada método deve executar uma tarefa bem definida.

Ver explicação

Evite misturar cálculos, exibição de mensagens e acesso ao banco de dados no mesmo método.

Métodos separados facilitam alterações e testes.

PRINCÍPIO 02

Funções pequenas

Prefira métodos curtos, desde que continuem claros e coesos.

Ver explicação

Métodos muito extensos podem esconder responsabilidades diferentes.

Não existe um número mágico de linhas. A clareza é mais importante que atingir um tamanho específico.

PRINCÍPIO 03

Parâmetros

Evite listas enormes de parâmetros difíceis de compreender.

Ver explicação

Muitos parâmetros podem dificultar a chamada e o teste de um método.

Quando os valores representam um mesmo conceito, considere agrupá-los em um objeto apropriado.

EXEMPLO EM C#

Separando responsabilidades

Os dois exemplos produzem o mesmo resultado. O segundo separa o cálculo da apresentação.

ANTES — RESPONSABILIDADES MISTURADAS

Um método faz tudo

void MostrarTotal(
    decimal preco,
    int quantidade)
{
    decimal total =
        preco * quantidade;

    Console.WriteLine(
        $"Total: {total:C}");
}

O método calcula o total e também decide como exibi-lo.

DEPOIS — RESPONSABILIDADES SEPARADAS

Métodos com objetivos claros

decimal CalcularTotal(
    decimal preco,
    int quantidade)
{
    return preco * quantidade;
}

void MostrarTotal(decimal total)
{
    Console.WriteLine(
        $"Total: {total:C}");
}

decimal total =
    CalcularTotal(20m, 5);

MostrarTotal(total);

Agora um método calcula o valor, enquanto outro apresenta o resultado.

PARTE 02

Clean Code na prática

Comparando nomes de variáveis em C#.

ANTES — POUCO CLARO

Nome genérico

int x = 20;
int y = 5;

int z = x * y;

Os nomes não explicam o significado dos valores.

DEPOIS — MAIS CLARO

Nome significativo

int preco = 20;
int quantidade = 5;

int total = preco * quantidade;

A intenção do cálculo fica muito mais fácil de entender.
