MISSÃO INICIAL

O que é Clean Code?

Clean Code é a prática de escrever código de forma clara, organizada e fácil de manter. Não basta funcionar: o código também precisa ser compreensível.

OBJETIVO

Por que isso importa?

Porque código confuso atrapalha manutenção, correções e evolução do sistema.

FOCO

O que vamos estudar?

Nomes significativos, funções, comentários, organização, legibilidade e boas práticas.
