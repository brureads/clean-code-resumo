01 / INTRODUÇÃO

O que é Clean Code?

É a prática de escrever código que seja fácil de ler, compreender e manter.

Entenda melhor

Clean Code significa código limpo. Um código de qualidade deve ser compreensível não apenas para quem o escreveu, mas também para outros desenvolvedores.

O objetivo é reduzir a complexidade desnecessária e facilitar futuras alterações no sistema.

02 / NOMENCLATURA

Nomes significativos

Variáveis, métodos e classes devem ter nomes que expliquem claramente sua finalidade.

Entenda melhor

Evite nomes genéricos como x, a, temp ou dados quando eles não comunicam o significado.

Prefira nomes específicos, como idadeUsuario, totalCompra ou calcularDesconto.

03 / ORGANIZAÇÃO

Funções

Cada função deve ter uma responsabilidade bem definida e ser fácil de entender.

Entenda melhor

Uma função deve executar uma tarefa bem definida, evitando acumular responsabilidades diferentes.

Funções pequenas e bem nomeadas costumam facilitar a leitura, os testes e a manutenção.

APROFUNDAMENTO

Nomes significativos

Um bom nome explica a intenção do código.

REGRA 01

Seja descritivo

Escolha nomes que mostrem o que uma variável, classe ou função representa.

EVITE

int x = 20;

PREFIRA

int idade = 20;
REGRA 02

Evite abreviações confusas

Abreviações pouco conhecidas dificultam a compreensão e exigem interpretação.

EVITE

int qtdUsr = 10;

PREFIRA

int quantidadeUsuarios = 10;
REGRA 03

Mantenha consistência

Siga as convenções da linguagem e mantenha o mesmo padrão no projeto.

EM C#

int totalCompra = 50;

PARTE 02

Clean Code na prática

Compare dois exemplos escritos em C#.

ANTES — POUCO CLARO

Nome genérico

int x = 20;
int y = 5;

int z = x * y;

O código funciona, mas os nomes não explicam o significado dos valores.

DEPOIS — MAIS CLARO

Nome significativo

int preco = 20;
int quantidade = 5;

int total = preco * quantidade;

Agora conseguimos entender a intenção do cálculo sem precisar investigar.
