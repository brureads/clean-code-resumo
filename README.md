
# Clean Code — Resumo Interativo

Um site de estudos desenvolvido para apresentar os principais conceitos de Clean Code de maneira visual, organizada e interativa.

O projeto reúne explicações objetivas, exemplos práticos em C#, flashcards e exercícios com correção automática.

## Sobre o projeto

O objetivo é tornar o estudo de boas práticas de programação mais acessível e interessante, utilizando uma interface moderna com fundo inspirado no universo, tons de rosa e cards interativos.

O conteúdo foi organizado para facilitar a consulta e a revisão dos assuntos.

## Conteúdos abordados

- Introdução ao Clean Code
- Nomes significativos
- Funções e métodos
- Comentários
- Formatação e organização
- Tratamento de erros

## Funcionalidades

- Cards com explicações expansíveis
- Exemplos de código antes e depois da refatoração
- Flashcards interativos
- Exercícios com correção automática
- Feedback explicativo das respostas
- Navegação entre assuntos
- Layout responsivo

## Tecnologias utilizadas

- HTML5 — estrutura e organização do conteúdo
- CSS3 — estilização, responsividade e layout
- JavaScript — interatividade e lógica dos exercícios
- Git e GitHub — versionamento e hospedagem do código

O projeto foi desenvolvido sem frameworks ou bibliotecas JavaScript externas.

## Estrutura do projeto

```text
clean-code-chalkboard/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Como executar

1. Clone o repositório ou baixe os arquivos.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

Observação: fontes e imagem de fundo externas precisam de conexão com a internet para carregar.

## Objetivo educacional

Além de funcionar como material de estudo, o projeto permite praticar conceitos de desenvolvimento web, incluindo:

- Estruturação semântica com HTML
- Layouts responsivos com CSS Grid
- Manipulação do DOM
- Eventos em JavaScript
- Funções reutilizáveis
- Organização e manutenção do código
